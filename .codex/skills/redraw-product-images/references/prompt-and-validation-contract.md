## 提示词交付格式

实际交给图片模型的提示词固定使用英文，并至少包含：

- `Use case`
- `Asset type`
- `Primary request`
- `Input images`
- `Scene/backdrop`
- `Subject`
- `Composition/framing`
- `Lighting/mood`
- `Constraints`
- `Avoid`

提示词必须把源图标记为 `Image 1: edit target and sole visual source of truth for the product`。产品名称和型号用于识别任务，不允许模型据此想象未显示的结构。

默认任务表达固定为：把源图转换成横向 `16:10` 的网站产品展示预览图，目标画布 `1600 × 1000`，产品完整、居中且不裁切。图片中不得增加任何文案；产品本体已有的 Logo、铭牌和型号属于产品事实，应原样保留。

每个提示词文件末尾附中文摘要，但调用图片模型时只提交 `--- IMAGE MODEL PROMPT ---` 与 `--- END IMAGE MODEL PROMPT ---` 之间的英文内容。

## 各模式提示规则

### 目录主图

- 使用 `precise-object-edit`。
- 使用横向 `16:10` 画布，目标 `1600 × 1000`，用于网站产品预览。
- 保持原视角、构图方向和完整主体。
- 允许清洁背景、均匀曝光、恢复自然对比度和合理边缘。
- 默认白色背景，留出均匀安全边距。
- 不增加落地阴影、镜面倒影、标题、副标题、卖点、规格、徽章、按钮、水印或装饰图形。

### 背景替换

- 明确 `change only the background`。
- 产品边缘、内部孔洞和透明区域必须保持。
- 不重新设计产品光照，不改变产品表面纹理。

### 透明切图

- 先遵循 `$imagegen` 的键控背景与本地去色流程。
- 验收透明角、主体覆盖率、边缘色溢出和 alpha 通道。
- 反光金属边缘不得因去背景出现绿色或品红色污染。

### 工业场景

- 使用 `compositing`，源产品仍是主体视觉真源。
- 场景只表达应用氛围，不表达具体安装合规性。
- 不添加看似真实但无法验证的管线连接、流向箭头、认证、参数或安全说明。
- 如果合成需要生成不可见产品面，停止并索取相应角度源图。

## 产品真实性检查

逐项对比源图与输出：

1. 外轮廓和长宽比例。
2. 产品观察角度和朝向。
3. 可见接口、法兰、螺纹、孔位和连接方向。
4. 零件数量、相对位置和遮挡关系。
5. 执行机构、手柄、显示器、传感器或线缆位置。
6. 材质、表面处理和品牌配色。
7. 铭牌、徽标、型号文字的位置与内容；看不清时输出也不得发明可读文字。
8. 磨损、倒角、铸造边缘等用于识别真实产品的细节。
9. 产品是否完整，没有被裁断或被场景物体遮盖关键部位。
10. 是否出现水印、虚构文字、额外配件或重复部件。
11. 最终画布是否为横向 `16:10`，产品是否完整且没有因裁切适配比例。

任一事实性结构不一致都判定失败。图片更美观、分辨率更高或背景更干净不能抵消真实性失败。

## 可接受与不可接受的变化

可接受：

- 背景颜色或透明度；
- `16:10` 画布尺寸和安全边距；
- 不改变材质意义的轻微曝光、白平衡和对比度调整；
- 产品之外的柔和环境阴影，仅限用户要求且不遮挡轮廓；
- 工业场景中的非事实性远景氛围。

不可接受：

- 改变产品角度以展示源图中不存在的面；
- 增删法兰、螺栓、阀杆、接口、显示器、线缆或附件；
- 修改品牌颜色、徽标、铭牌和型号；
- 把同系列外观替换成当前型号；
- 生成技术参数、认证、安全标识或尺寸标注；
- 新增标题、副标题、卖点、徽章、按钮、水印或任何其他文案；
- 为了构图裁掉产品关键部位。

## 发布交接

向发布工作流交付：

- 源图片绝对路径；
- 最终图片绝对路径；
- 英文提示词文件；
- 中文摘要；
- 模式和用途：主图或图库；
- 尝试次数；
- 视觉验收清单和结论；
- 是否使用透明背景或 AI 场景。
- 最终画布尺寸和 `16:10` 比例检查结果。

只有结论为 `accepted` 的输出才能进入 CMS 媒体上传。
