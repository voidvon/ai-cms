# 专题树功能设计

## 结论

热门系列功能使用现有 CMS 的「栏目树 + 数据库模板绑定 + 跨模型内容聚合」实现。

- 栏目树负责热门系列层级、URL、导航、列表页和模板绑定。
- 热门系列不使用独立内容模型；页面内容来自产品、资料、文章、FAQ、案例等已有内容模型的聚合。
- 栏目自身的标题、摘要、SEO 和页面配置使用 `column_translations` 与 `template_data_json` 表达。
- 不新增独立专题路由，不手改 `html/`，不绕开现有静态生成链路。

## 为什么用栏目树

当前关键词已经存在明显树形关系。例如：

- 疏水阀
  - 浮球式疏水阀
  - 热动力疏水阀
  - 恒温/平衡压力疏水阀
  - 倒吊桶疏水阀
- 减压阀
  - 先导式减压阀
  - 直接作用式减压阀
  - 减压站
- 过滤器
  - Y 型过滤器
  - 篮式过滤器
  - 蒸汽/洁净蒸汽过滤器
- 冷凝水泵
  - 泵疏水阀/APT
  - 冷凝水回收泵组
- 止回阀
  - 圆盘止回阀
  - 对夹式止回阀
- 汽水分离器
  - 蒸汽分离器
  - 压缩空气分离器

这些结构天然适合栏目树。栏目树可以表达父子系列，并让每个系列栏目拥有独立 URL 和模板绑定。

## 栏目配置

热门系列不新增 `topic` 内容模型，也不维护 `content_topic` 数据表。

栏目配置承载：

- `column_translations.name`：栏目显示名称。
- `column_translations.summary`：栏目简介。
- `column_translations.content_html`：栏目说明或编辑型正文。
- `column_translations.seo_title`、`seo_description`：栏目 SEO。
- `column_translations.template_data_json`：页面类型、聚合规则、模块配置。

热门系列根栏目使用：

```json
{
  "pageKind": "series-tree",
  "renderFullSectionTree": true
}
```

具体聚合内容后续应通过栏目模板或栏目配置读取已有内容模型，不再创建专题内容记录。

## URL 建议

建议创建一个热门系列根栏目：

```text
/topics/
```

然后按关键词树建立子栏目：

```text
/topics/steam-traps/
/topics/steam-traps/float-steam-traps/
/topics/steam-traps/thermodynamic-steam-traps/
/topics/pressure-reducing-valves/
/topics/pressure-reducing-valves/pilot-operated-pressure-reducing-valves/
```

每个热门系列页面直接渲染栏目页，不再生成专题内容详情页。

## 建热门系列的筛选标准

优先建热门系列栏目：

- 有搜索量或关键词数量明显较高。
- 能对应明确产品族、产品类型或解决方案。
- 能支撑独立内容，包括选型、工作原理、关联产品、应用场景、FAQ 和资料下载。
- 可以作为其它页面的内部链接枢纽。

暂不单独建热门系列：

- 只有规格、尺寸、材质、压力等级、连接方式等属性词。
- 只有单个型号且无法支撑独立内容。
- 搜索意图更像资料查询、价格查询、说明书查询，而不是产品/方案页面。

这些词更适合作为筛选项、FAQ、产品参数或资料模块内容。

## 初始种子

初始专题树数据见：

```text
docs/关键词列表/按产品系列类型拆分/专题树种子.json
```

这份 JSON 先作为建栏目依据，不直接写数据库。后续如果需要批量导入，可以基于这份结构再写导入脚本，调用现有栏目 API。

## 后续增强

建议后续分三步做：

1. 在后台提供热门系列栏目批量创建/导入能力。
2. 为栏目 `template_data_json` 增加可视化聚合规则配置。
3. 在数据库模板中新增热门系列栏目模板变体，通过现有模板绑定和静态生成发布。
