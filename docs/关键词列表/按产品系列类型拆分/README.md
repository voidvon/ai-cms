# 按产品系列类型拆分关键词

- 来源型号表：`全部产品型号列表.md`
- 来源关键词备份：`全球EN站关键词合并去重.抽离产品型号前备份.csv`
- 当前剩余关键词文件：`全球EN站关键词合并去重.csv`
- 原始关键词行数：5624
- 当前剩余关键词行数：15
- 非产品属性归档关键词行数：2256
- 已生成产品系列/类型文件数：91
- 人工语义分类命中记录数：2504

处理口径：先按 `全部产品型号列表.md` 中的产品型号抽离；再对剩余关键词做人工语义归类，把明确属于产品系列/类型的非型号词移入对应 CSV，并从 `全球EN站关键词合并去重.csv` 删除。明确属于地区、公司、招聘、股价、供应商、教程、纯蒸汽知识等非产品意图的词已归档到 `非产品属性拆分/`；仍无法稳定归类的长尾词保留在总表。

型号匹配规则：按关键词和备注中的独立产品型号 token 匹配；允许型号内部空格、连字符、点号差异，例如 `APT 14` 可匹配 `APT14`，`APT104.5` 可匹配 `APT10-4`；重叠命中时保留更长型号；同一文件内按完整 CSV 行去重。

人工语义归类规则见：`人工语义分类规则.csv`；人工归类记录见：`人工语义分类摘要.csv`。

自动批处理进度见：`自动型号分类候选.csv`、`自动型号分类进度.csv`。

非产品属性归档见：`非产品属性拆分/`，用于存放明确以规格参数、材料牌号、资料编号、零件/物料号、标准法规、资源格式、公司品牌、投资者财务、招聘雇主、采购渠道、资料下载、培训教程、工程工具、技术知识、方案服务、站内导航与通用查询、噪声与无效查询等为主的关键词，不计入产品系列/类型文件数。
