处理口径：从剩余关键词中抽离主要意图不是产品系列/类型，而是规格、材料、编号、公司、投资者、招聘、渠道、资料、培训、工具、知识参考、地区分支、新闻事件、方案服务、站内导航与通用查询、噪声与无效查询等非产品属性或非产品意图的关键词。部分关键词同时带有产品词、型号词或语言变体，但当前可稳定识别的主信号是属性、资源、公司、业务或无效噪声意图，因此先归入本目录，避免混入产品系列统计。

未归档口径：仍无法稳定判断为产品、公司、资源、渠道或知识意图的长尾词继续保留在总表；带明确产品类型但缺少足够上下文的词，也暂不强行移动。
