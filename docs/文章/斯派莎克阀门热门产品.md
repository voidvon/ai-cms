## 1. 减压阀、调节阀与溢流阀

[减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/)用于将上游较高压力稳定降低到下游工艺需要的压力，是蒸汽分配、换热设备供汽、公用工程支路和 OEM 成套设备中非常常见的阀门类型。溢流阀或背压阀则用于维持上游压力、释放多余压力或保护系统稳定。需要了解蒸汽压力控制原理时，可参考[压力控制应用](/learn-about-steam/control-applications/pressure-control-applications/)和[自作用压力控制](/learn-about-steam/control-hardware---self-acting-actuation/self-acting-pressure-controls-and-applications/)。

斯派莎克减压阀产品通常可分为直接作用式、导阀型、自作用式以及站组化压力控制方案。选型时建议重点核对上游压力、下游设定压力、负荷变化范围、介质类型、连接方式、控制精度和是否需要旁通或安全附件。

| 产品方向 | 常见型号 / 系列 | 适用说明 |
| --- | --- | --- |
| 导阀型减压阀 | 25P、DP27、DP143、DP163 | 适合蒸汽主管、支路和负荷变化较大的压力控制 |
| 直接作用式减压阀 | BRV2S、BRV2B、BRV71、BRV73、DRV4、DRV7 | 结构相对简单，适合小中型设备和局部稳压 |
| 小流量或特殊应用 | SRV2S、SRV461、SRV463、SRV505、SRV66 | 可按介质、卫生等级或小流量需求进一步选择 |
| 溢流和背压控制 | DEP4、DEP7、SDP143 | 用于背压、保压或上游压力释放场景 |

如果搜索词中包含 `pressure reducing valve`、`pressure regulator`、`steam regulator`、`25P`、`DP27`、`BRV2S` 等，通常应优先进入减压阀或蒸汽压力控制页面。当前中文站已有 [25P 减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/25p-pressure-reducing-valve/)、[DP27 减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/dp27-pressure-reducing-valve/)和 [BRV2S 减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/brv2s-pressure-reducing-valve/)等产品详情入口。

## 2. Spira-trol 控制阀

[Spira-trol 控制阀](/products/control-systems/control-valves/)是斯派莎克面向通用工业过程控制的模块化控制阀平台，适用于蒸汽及其他工业流体控制。它不是单一型号，而是由阀体、阀内件、执行器、定位器和附件组合形成的控制阀系统。

![Spira-trol 控制阀结构示意](assets/spirax-spira-trol-control-valve.png)

Spira-trol 控制阀可以根据阀体材质、口径、连接方式、流量特性、阀杆密封、阀内件形式和驱动方式进行组合。对于需要连续调节的蒸汽系统，控制阀选型通常要同时考虑压差、噪音、气蚀、关断等级、阀内件寿命和执行器安全位置。

| 选型维度 | 可关注内容 |
| --- | --- |
| 阀体与连接 | ANSI 或 EN 标准，法兰、螺纹、承插焊等连接形式 |
| 阀体材质 | 球墨铸铁、碳钢、不锈钢、合金钢 |
| 流量特性 | 等百分比、线性、快开 |
| 阀内件 | 标准阀内件、降噪阀内件、抗气蚀阀内件、多级鼠笼阀内件 |
| 驱动方式 | 气动执行器、电动执行器 |
| 配套附件 | SP400/SP500 定位器、EP500、PN9000、AEL 系列执行器 |

常见相关关键词包括 `Spira-trol`、`Spirax Sarco control valve`、`steam control valve`、`control valve sizing`、`KE73`、`EP6`、`BCV43` 等。工程计算和基础知识可进一步阅读[控制阀](/learn-about-steam/control-hardware-electric-pneumatic-actuation/control-valves/)、[蒸汽系统控制阀选型](/learn-about-steam/control-hardware-electric-pneumatic-actuation/control-valve-sizing-for-steam-systems/)和[控制阀执行器与定位器](/learn-about-steam/control-hardware-electric-pneumatic-actuation/control-valve-actuators-and-positioners/)。

## 3. 阀门定位器与执行器

[阀门定位器](/products/control-systems/positioners-controllers-and-sensors/)用于控制执行机构的开度，并把控制信号转化为稳定、可重复的阀门位置。对于蒸汽控制阀、过程控制阀和自动化阀门系统，定位器会直接影响控制精度、响应速度、调试效率和维护工作量。

![SP400 与 SP500 智能数字阀门定位器](assets/spirax-sp400-sp500-positioner.png)

斯派莎克 SP400 和 SP500 是常见智能数字式电气气动阀门定位器。两者都支持 4-20 mA 输入，强调低耗气、快速调试和可靠的位置反馈。SP400 更适合基础定位功能，SP500 则更适合需要更多可编程功能、通讯能力和附加模块的场景。

| 产品 | 适合场景 |
| --- | --- |
| [SP400](/products/control-systems/positioners-controllers-and-sensors/sp400-smart-positioner/) | 基础调节任务、OEM、一般过程装置、预算敏感项目 |
| [SP500](/products/control-systems/positioners-controllers-and-sensors/sp500-smart-positioner/) | 需要更强可调性、通讯扩展、反馈模块或诊断能力的控制回路 |
| [SP7-10 / SP7-11 / SP7-12](/products/control-systems/positioners-controllers-and-sensors/sp7-smart-positioner/) | 智能定位器应用，适合更复杂的安装和通讯需求 |
| EP500 / EP6 | 电气气动定位器相关应用 |
| [PN9000 / PN9400](/products/control-systems/pneumatic-actuators/) | 气动执行器，可与控制阀组成气动控制方案 |
| [AEL6 / AEL7 / AEL8](/products/control-systems/electric-actuators/) | 电动执行器，可用于电动控制阀方案 |

如果页面后续扩展为产品中心，建议把“阀门定位器”和“执行器”作为控制阀页面的重要内链，而不是孤立放在仪表栏目中。

## 4. 安全阀与泄压保护

[安全阀](/products/control-systems/safety-valves/)用于防止蒸汽、压缩空气、锅炉和过程系统超压，是保护人员、设备和生产连续性的关键部件。在锅炉、压力容器、减压站和过程系统中，安全阀通常是最后一道超压保护。

![斯派莎克安全阀产品示意](assets/spirax-safety-valves.png)

安全阀选型不能只看口径，还需要结合设定压力、排放能力、介质、温度、材料、连接标准、法规要求和维护校验周期综合判断。对于洁净蒸汽或卫生工艺，还需要额外关注材料可追溯、连接方式和清洁要求。

| 产品方向 | 常见型号 / 系列 | 适用说明 |
| --- | --- | --- |
| 通用工业安全阀 | SV60、SV73、SV74、SV615 | 用于蒸汽、压缩空气和一般过程系统保护 |
| 洁净或卫生应用 | [SVL488](/products/clean-steam/svl488-clean-service-safety-valve/)、SVL606 | 用于洁净蒸汽、食品饮料、制药等场景 |
| 泄压相关查询 | pressure relief valve、safety relief valve | 应与安全阀页面或泄压保护页面形成内链 |

安全阀页面的内容应保持工程边界：具体选型必须基于系统设计压力、允许超压、排放能力和当地法规，不能仅凭型号列表替代工程计算。技术学习可参考[安全阀基础知识](/learn-about-steam/safety-valves/)、[安全阀选型](/learn-about-steam/safety-valves/safety-valve-selection/)和[安全阀口径计算](/learn-about-steam/safety-valves/safety-valve-sizing/)。

## 5. 止回阀与防回流保护

[止回阀](/products/pipeline-ancillaries/check-valves/)用于防止介质倒流，保护流量计、控制阀、工艺设备和敏感仪表。它通常安装在蒸汽、冷凝水、工艺流体、泵出口、流量测量和卫生系统等需要明确单向流动的位置。

![斯派莎克止回阀产品示意](assets/spirax-check-valves.png)

| 类型 | 常见型号 | 主要特点 |
| --- | --- | --- |
| 圆盘式止回阀 | DCV1、[DCV3](/products/pipeline-ancillaries/check-valves/dcv3-disc-check-valve/)、DCV4、DCV6、DCV8、DCV10、DCV41 | 结构紧凑，响应快，适合一般工业管线 |
| 双瓣式 / 摆动式止回阀 | SDCV3、SDCV4、SDCV7、SDCV8、WCV 系列 | 适合较大口径或低压降需求 |
| 升降式止回阀 | LCV1、LCV3、LCV4、LCV6、LCV7 | 结构简单，维护量较低 |
| 卫生级止回阀 | CVS10 | 适合食品、制药和高纯度流体系统 |

关键词中出现 `check valve`、`non return valve`、`disc check valve`、`DCV4`、`DCV41`、`CVS10` 时，应优先匹配止回阀产品页或具体型号页。原理内容可补充阅读[管路附件中的止回阀](/learn-about-steam/pipeline-ancillaries/check-valves/)。

## 常见问题

### 斯派莎克阀门选型应先看哪些参数？

优先确认介质、上游压力、下游压力或设定压力、工作温度、流量范围、管径、连接标准、阀体材质、控制精度、安装空间和维护方式。对于安全阀、减压阀和控制阀，还应结合系统保护要求、排放能力、压差和负荷变化范围判断。

### 减压阀和控制阀有什么区别？

[减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/)主要用于把上游压力降低并稳定在目标压力；[控制阀](/products/control-systems/control-valves/)则通常接收控制信号，通过执行器和定位器连续调节阀门开度，用于压力、温度或流量控制。复杂工况下，两者可能同时出现在同一蒸汽控制系统中。

### 安全阀可以只按口径选择吗？

不建议。安全阀选型必须结合设定压力、允许超压、排放能力、介质、温度、连接标准、法规要求和校验维护策略。对于蒸汽系统，可先阅读[安全阀选型](/learn-about-steam/safety-valves/safety-valve-selection/)和[安全阀口径计算](/learn-about-steam/safety-valves/safety-valve-sizing/)。

### 哪里可以找阀门样本、手册和设计工具？

可先进入[资源与设计工具](/resources-and-design-tools/)查找资料和计算工具，也可以从具体产品页进入相关资料。若需要基于现场工况确认型号，可通过[联系我们](/contact-us/)获取进一步支持。

斯派莎克阀门产品不应按单一“阀门”概念粗略归类。更合理的查找方式是先判断系统位置和控制目标，再进入对应产品族：压力控制选择[减压阀](/products/control-systems/pressure-reducing-and-surplussing-valves/)和调节阀，过程控制选择 [Spira-trol 控制阀](/products/control-systems/control-valves/)及[定位器](/products/control-systems/positioners-controllers-and-sensors/)，系统保护选择[安全阀](/products/control-systems/safety-valves/)和[止回阀](/products/pipeline-ancillaries/check-valves/)，维护隔离选择[球阀](/products/isolation-valves/ball-valves/)和[截止阀](/products/isolation-valves/bellows-sealed-stop-valves/)，锅炉房则需要[排污控制](/products/boiler-controls-and-systems/tds-blowdown-controls/)、控制器和安全保护组合。
