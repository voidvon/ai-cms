     压力感应管安装

    • 规格：可用 5/16” 外径接管（压缩式连接件）或 1/4” 接管

    • 位置：接在被减压管道顶部，距减压阀 10 倍管径，距下游弯头 / 阀门等节流元件 0.3 米；若供单个设备，可装在设备蒸汽空间内

    • 辅助：装隔离阀（方便维修关闭），管道需斜向下游（防积液）

    4. 其他关键配件

    配件要求
    旁通建议安装，与减压阀同口径，维修时无需停机
    疏水阀蒸汽管路装斯派莎克疏水阀；下游提升管道底部装疏水阀（防水锤）
    过滤器上游装 100 目过滤器（侧向安装），过滤器与减压阀间留足够空间（方便取滤网、排污）
    截止阀阀门及感应器上下游用全通径截止阀，保证额定流量与控制效果
    汽水分离器减压站距上游分离点超 15 米，或冷凝水多，需在站前装分离器
    安全阀下游装安全阀（设定压力低于设备安全压力），排放管接安全区域；选型考虑减压阀最大流量

    5. 特殊场景

    • 并联 / 串联：大流量 / 可变负载 / 需备用，可 2 个及以上阀门并联（设定压力略不同，依次开启）；压力调节比超 10:1，需串联（阀间管道长 50 倍管径，装疏水阀）

    • 防冻：环境温度低于冰点，需做防冻保护（阀门无自排放功能，防阀体冻坏）

    二、工作原理与启动步骤

    1. 工作原理

    • 初始：主阀关，导阀开（弹簧力作用）；蒸汽经导阀进主隔膜室，部分从控制孔流出

    • 调节：导阀进汽＞控制孔出汽→主隔膜室压力升→主阀开；下游压力经感应管反馈至导阀隔膜下部，平衡弹簧力→导阀关小→维持主隔膜室压力→控制主阀开度

    • 停汽：无需蒸汽时，感应管压力升→导阀关，控制孔泄压→主阀关

    2. 启动步骤

    1. 确认所有截止阀关闭

    2. 取下导阀弹簧帽，逆时针旋调节螺栓（2D）至弹簧松弛，确保弹簧垂直、在导座中心

    3. 开阀顺序：①开蒸汽主管疏水阀前截止阀（排冷凝水）→②开感应管隔离阀→③开下游截止阀→④缓慢开入口截止阀

    4. 顺时针慢旋调节螺栓（2D），至下游压力表显示目标压力

    5. 系统稳定后，可再次微调导阀弹簧，装好弹簧罩并拧紧锁紧螺母

    6. 检查导阀法兰接口，确保无泄漏

    三、故障诊断（简表）

    故障现象常见原因检修方法
    正常负载时控制压力超设定值导阀阀芯 / 阀座有杂质；主阀阀芯 / 阀座有杂质；控制孔 / 感应管堵塞松调节螺栓（2D），拆铜管接头（J&L）通蒸汽，漏汽则拆导阀组件清洗 / 更换；检查清洗主阀阀芯 / 阀座；拆洗控制孔 / 感应管
    低负载时控制压力超设定值主阀阀芯 / 阀座磨损 / 有杂质；阀门选型过大；旁通阀漏；主阀阀杆有杂质清洗 / 检修主阀；低负载下调调节螺栓（2D）；修旁通阀；拆洗主阀阀杆
    减压阀打不开主阀隔膜破；控制孔（H）堵；导阀阀座堵；过滤网 / 管道过滤器堵；调节螺栓（2D）调错关旁通阀，拆（G）处接管，漏汽则换隔膜；拆洗控制孔 / 导阀阀座 / 滤网 / 过滤器；调对调节螺栓
    控制压力过低调节螺栓（2D）调错；阀门选型过小；供应蒸汽压力低；主阀隔膜破调对调节螺栓；校核流量，换合适阀门；检查校正蒸汽压力；换隔膜
    减压阀关不上泄流孔（B）接头丢；感应管堵 / 未装；导阀 / 主阀隔膜破；导阀 / 主阀阀座螺纹坏换接头；拆洗 / 安装感应管；换隔膜；检查阀座冲蚀，维修 / 更换
