    斯派莎克 Spira-trol™ 二通控制阀 LE/LF/LL & LEA/LFA/LLA

    产品定位

    斯派莎克 Spira-trol™系列二通控制阀，专为蒸汽、热水、导热油及工业流体精密调节设计，覆盖DN15~DN100（½"~4"），适配暖通、换热、工艺系统高精度流量控制。

    核心优势

    1. 三档流量特性，精准匹配工况

      • 等百分比：蒸汽 / 变压降系统最优

      • 线性：液体 / 恒压降系统

      • 快开：开关控制场景

    2. 宽温域密封，零泄漏可靠

      • PTFE/PEEK 软阀座达 Class VI 级泄漏

      • 波纹管 / 石墨密封，高温无外漏

      • 耐温最高538℃，适用导热油与高压蒸汽

    3. 材质全覆盖，工况适应性强

      • 铸铁 / 碳钢 / 不锈钢三档阀体

      • 硬化阀内件耐冲刷、长寿命

    4. 模块化设计，易维护

      • 顶部拆装，在线更换阀内件

      • 加长阀帽适配保温与高低温工况

    5. 全系列执行器配套

      • 气动 / 电动执行器 + 智能定位器

      • 支持远程控制、闭环调节

    型号速览

    • LE/LEA：等百分比调节

    • LF/LFA：快开开关型

    • LL/LLA：线性液体控制

    • 31/33：铸铁；43：碳钢；63：不锈钢

    • LEA：英制 NPT/ASME 法兰；LE：公制 BSP/PN 法兰

    关键参数

    • 口径：DN15~DN100 / ½"~4"

    • 压力：PN16、Class 125/150、JIS10

    • 温度：-29℃~538℃

    • 调节比：最高50:1

    • 泄漏等级：Class IV / V / VI

    • 认证：EN 60534、PED 2014/68/EC、EN 10204 3.1

    适用场景

    蒸汽换热、空调热水、导热油系统、工艺流体调节、锅炉辅机、石化 / 轻工 / 暖通自控系统。

    Spira-trol™ DN15-DN100，LE，LF 和 LL 及 ½"-4" LEA，LFA 和 LLA 二通控制阀

    口径及管道连接

    • 铸铁阀体

      • 螺纹 BSP：LE31，DN15~DN50

      • 螺纹 NPT：LEA31，½"~2"

      • 法兰 EN1092 PN16/JIS KS10：LE33，DN15~DN100

      • 法兰 ASME 125/JIS KS10：LEA33，1"~4"

    • 碳钢阀体

      • 法兰 EN1092 PN16/JIS KS10：LE43，DN15~DN100

      • 法兰 ASME 150/JIS KS10：LEA43，½"~4"

    • 不锈钢阀体

      • 法兰 EN1092 PN16/JIS KS10：LE63，DN15~DN100

      • 法兰 ASME 150/JIS KS10：LEA63，½"~4"

    流量特性

    • LE/LEA：等百分比 (E)，通用调节

    • LF/LFA：快开 (F)，开关控制

    • LL/LLA：线性 (L)，液体 / 恒压降控制

    阀杆密封

    • PTFE 密封（标准）

    • 波纹管 / 石墨 (D)：零泄漏、高温

    • 石墨填料：高温

    阀座

    • ≤170℃：PTFE，Class VI

    • ≤220℃：PEEK(C/P)，Class VI

    • ≤250℃：PEEK(K)，Class VI

    • 硬化表面：316L+Stellite 6

    阀帽

    • 标准阀帽

    • 加长阀帽：保温 / 冷热工况

    执行器与定位器

    • 气动执行器：EL4600、AEL3/5/6、PN9000 系列

    • 定位器：PP6、SP400、SP500

    标准与认证

    • 符合 EN 60534、欧盟压力设备指令 2014/68/EC

    • 可提供 EN 10204 3.1 证书

    技术数据

    • 阀芯设计：抛物线

    • 泄漏等级：Class IV / V / VI

    • 调节比：等百分比 50:1；线性 30:1；快开 10:1

    • 行程：DN15~DN50 为 20mm；DN65~DN100 为 30mm

    材质要点

    • 铸铁：EN-GJS-400-18、ASTM A126B/A395

    • 碳钢：EN 10213 GP240GH、ASTM A216 WCB/A105N

    • 不锈钢：EN 1.4408、ASTM A351 CF8M、AISI 316L

    • 阀杆 / 阀芯：AISI 431、316L

    • 填料：PTFE、石墨、Viton

    Kv/Cv 值

    Cv (US)=Cv (UK)×1.2009标准等百分比 / 线性 Kv：DN15=4.6…DN100=185.0支持多档缩小阀内件与微小流量阀芯

    压力温度限值

    • LE31/33：PN16，最高 300℃

    • LE43：PN16，最高 400℃

    • LE63：PN16，最高 400℃

    • LEA31/33：ASME 125，最高 232℃

    • LEA43：ASME 150，最高 425℃

    • LEA63：ASME 150，最高 538℃

    • 软阀座限制：PTFE≤170℃，PEEK≤220℃

    • 最小温度：-10℃ /-29℃

    • 最大压差：PTFE/PEEK 分体 7bar；整体 PEEK 19bar

    • 冷态水压：21~29.5bar g

    尺寸、重量、执行器参数

    提供螺纹 / 法兰外形尺寸、整机重量、气动 / 电动执行器尺寸重量

    备件

    • 标准阀：执行器螺母、垫片、填料、阀芯阀座、软阀座等

    • 波纹管密封：增加波纹管组件
