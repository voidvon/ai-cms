    LC2650液位控制器 电导率控制器 导电液位流体

    一、产品简介

    LC2650 是适用于导电流体的液位控制器，用于锅炉、水箱及容器的液位开关或调节控制，最大工作压力 32bar@239°C。

    • 具备两路报警通道，可独立设置高 / 低报警

    • 适用最低电导率：5μS/cm 或 5ppm（搭配 LP20/PA20）

    • 正面配置LCD 液晶显示屏+5 个操作按键

    • 运行模式可显示实时数据，支持液位波动趋势图

    • 内置测试菜单，具备输入测量与输出设置诊断功能

    • 全部调试参数密码保护，防止误修改

    • 支持红外通讯，可设为主站 / 从站

    • 安装方式：面板安装、DIN 导轨安装、底板安装

    二、主要特点

    • 采用电容式感应，实现锅炉水位调节 / 开关控制

    • 支持积分参数可调，支持单 / 双 / 三冲量控制

    • 图形 LCD 显示：运行状态、测量值百分比、报警信息、趋势曲线

    • 通讯方式：红外通讯、EIA 485/Modbus

    • 通过UL、TUV认证

    • 适用于重工业环境，满足严苛 EMC 要求

    三、认证标准

    • 电磁兼容：符合 2017/30/EU 指令

    • 安全标准：EN 61010-1:2001（测量 / 控制 / 实验室电气设备安全）

    • 型式认证：Vd TÜV 水控制设备 100 (07:2006)、UL 认证

    • EMC 评估编号：UK Supply BH LC2650 2008

    四、典型应用

    通过控制泵、阀门或电磁阀，实现锅炉 / 水箱 / 容器水位控制。

    1. 开关控制

    • 泵开关控制

    • 两路报警输出

    • 隔离型 4-20mA 液位信号输出

    • 可选用电磁阀控制替代泵控制

    2. 调节控制

    • 阀门驱动 / 4-20mA 信号控制

    • 两路报警输出

    • 隔离型 4-20mA 液位信号输出

    3. 双 / 三冲量调节控制

    • 阀门驱动 / 4-20mA 信号控制

    • 两路报警输出

    • 隔离型 4-20mA 液位信号输出

    • 支持蒸汽流量计反馈

    • 支持给水流量前馈

    五、输入与输出

    • 输入：将信号与设定值比较，输出控制信号调节水位

    • 输出：可接泵 / 调节阀；提供高低报警继电器输出、隔离 0-20mA/4-20mA 输出

    • 支持RS485/Modbus远程参数传输

    • 内置滤波功能，抑制液位波动，提升稳定性

    六、技术参数

    电源

    • 电压：110–240 VAC，50/60Hz

    • 最大功耗：7.5W

    环境条件

    • 使用场所：仅限室内

    • 最高海拔：2000m

    • 环境温度：0–55°C

    • 相对湿度：31°C 时 80%，40°C 时线性降至 50%

    • 过电压类别：III

    • 污染等级：2（出厂）/3（装盒后，最低 IP54）

    • 前面板防护：IP65、NEMA 4（UL 认证）

    外壳与接线

    • 外壳：聚碳酸酯，蓝色（294）

    • 前面板：硅橡胶，60 Shore

    • 焊料：锡 / 铅（60/40%）

    • 接线端子：插拔式螺丝端子

    • 适用线径：0.2–2.5mm²（24–12AWG），剥线长度 5–6mm

    线缆规格

    • 液位传感器（高温屏蔽）：3 芯，1–1.5mm²，最大 100m

    • 4-20mA 输出：屏蔽双绞线，单芯，0.23–1mm²，最大 100m

    • RS485 通讯：EIA RS485 屏蔽双绞线，2/3 对，0.23mm²，最大 1200m（超五类线限 600m）

    电气性能

    • 液位输入电压：0–6Vdc（绝对最大 7Vdc），输入阻抗 28kΩ

    • 精度：±5% FSD；重复性：±2.5% FSD；分辨率：14 位

    • 采样速率：260Hz

    • 4-20mA 输出：负载最大 500Ω，分辨率 1% FSD

    • 继电器输出：2×SPCO，250Vac，阻性 3A，感性 1A

    • RS485：Modbus RTU，全 / 半双工

    • 红外通讯：IrDA，波特率 38400，距离 10cm，角度 15°

    • 激光安全：EN 60825-12:2007，1 类

    七、安全、安装与维护

    • 警告：产品带危险电压，安装前务必阅读随附安装维修手册

    • 接线前确保内部无冷凝水

    • 必须安装在工业控制柜或防火外壳内，防护不低于IP54

    • 无额外防护时禁止室外安装

    • 产品密封不可拆解，无内部可更换部件

    • 不可遮挡红外通讯窗口

    • 接线符合 EN/IEC 标准，英国遵循 BS 7671

    • 无需日常维护，锅炉水位控制与报警需定期检测

    • 参考安全规范：BG01、INDG436

    八、尺寸与重量

    • 尺寸（约）：140mm×120mm×52mm

    • 重量：约 550g

    九、产品说明与订购

    • 产品：液位控制器，双路报警（高 / 低可设），红外通讯，主 / 从站可选

    • 订购示例：1× 斯派莎克 LC2650 液位控制器
