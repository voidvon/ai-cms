    EL3501电动执行器 EL3502线性电动头调节阀SE

    1 执行器安装安全须知

    通用安全

    • 操作前必须完整阅读本手册及安全指南 IM-GCM-10，并遵守当地法规。

    • 不当使用可能导致人身伤害、设备损坏或性能下降。

    • 执行器为Ⅱ 类防护，依赖外部过载保护与隔离装置。

    接线安全要点

    1. 维护人员必须具备高压操作资质。

    2. 拆装前必须切断主电源。

    3. 外部电路需满足双绝缘（IEC 60364 或等效标准）。

    4. EL3512/SE/SR 相线需加装 100 mA/250 V 熔丝，严禁接在接地线上。

    5. 系统必须配置易操作、明显标识的断路装置，触点断开距离≥3 mm。

    6. 不得断开保护接地线，断路装置需符合 IEC 947-1 / IEC 947-3。

    电磁兼容（EMC）

    • 产品符合 CE、73/23/EEC、89/336/EEC 要求。

    • 3 米内使用手机、靠近发射台、电源噪声过大可能产生干扰。

    • 电源噪声大时建议加装电源滤波 / 稳压 / 浪涌抑制装置。

    2 产品简介

    2.1 用途

    EL3500 系列为线性电动执行器，可配套：

    • KE/LE 两通阀（DN15–DN50）

    • 自作用阀（BX、SB、KA、KB、KC）

    • TW 三通阀支持：开关控制、外置马达开关调节、0–10V / 2–10Vdc 模拟调节。

    2.2 型号编码规则

    • EL35xx：系列

    • 0=VMD 控制；1=0/2–10V 调节

    • 1=230Vac；2=24Vac

    • SE = 弹簧断电伸张；SR = 弹簧断电回缩

    型号示例：EL3501SE — 230Vac、VMD 控制、断电弹簧伸张。

    2.3 运行参数

    • 驱动：同步电机 + 齿轮箱 → 线性运动

    • 额定推力：≤600 N

    • 标准行程：20 mm

    • 内置微动开关，到位自动断电

    2.4 手动调节

    • 无弹簧型（EL3501/3502/3512）：手轮直接操作。

    • 弹簧预制型（SE/SR）：手轮在端盖内，按压后转动即可驱动阀杆。

    3 安装

    3.1 安装定位

    • 执行器装在阀门上方，预留拆装空间。

    • 环境条件：温度 -10℃ ~ +50℃，湿度 5%~95%RH。

    • 防护等级：IP54（端盖、接线正确安装时）。

    3.1.1 介质温度与安装角度

    1. ≤150℃：标准安装，0°~90° 垂直范围。

    2. 150℃~220℃：必须用 EL3905 高温组件，0°~90°。

    3. 220℃~250℃：必须用 EL3905，仅允许 45°~90°，禁止垂直安装。

    3.2 阀门连接件安装

    安装执行器必须用手轮操作，禁止通电驱动。

    3.2.1 KE/LE 阀连接件

    • 老 KE（M30 压盖）：EL3904

    • 新 KE（M34 压盖）：EL3906

    • 安装要点：阀杆完全关闭 → 装锁定螺母 → 调整高度 89±0.5 mm → 锁紧 → 装执行器。

    3.2.2 自作用阀连接件

    • 用 EL3808 / EL3809 转接件。

    • 调整高度：78±0.5 mm → 锁紧固定。

    3.3 执行器本体安装

    1. 松开 U 型螺栓保护螺母。

    2. 将执行器装在轴环肩上，推动弹簧负载板嵌入阀杆。

    3. 释放负载板自动锁紧。

    4. 螺母拧紧力矩：4 Nm。

    3.4 端盖拆装

    • 拆前断电。

    • 松开 2 颗螺钉即可取下；复装时不要过度拧紧。

    3.5 附件安装

    表格

    附件型号名称
    EL3901辅助电位计 10 kΩ
    EL3902辅助电位计 220 Ω
    EL3903辅助开关
    EL3905高温组件

    3.5.1 辅助电位计

    1. 执行器全伸（阀关）。

    2. 电位计轴顺时针旋到底。

    3. 固定电位计，按图接线，整理线束防割破。

    4. 测试全行程电阻变化正常。

    3.5.2 辅助开关

    1. 先装电位计（如有），再装开关。

    2. 固定开关组，接线，调整凸轮设定开关点。

    3.5.3 EL3905 高温组件（LE/KE）

    1. 装螺纹环管 → 装延伸轭 → 装转接件。

    2. 高度调至 89±0.5 mm 并锁紧。

    3. 不可与 EL3906 共用。

    3.6 电气接线

    通用要求

    • 电源线：1.5 mm²，双绝缘线。

    • 相线装熔丝，接地线严禁装熔丝。

    • 保护接地可靠连接。

    型号与接线对应

    表格

    型号电压控制信号

    EL350224VacVMD
    EL3501SE230VacVMD

    3.6.2 VMD 型（EL3501/3502/SE）

    • 端子 3 = 伸张，4 = 回缩。

    • SE 型：端子 2 接电源，断电弹簧全伸张。

    3.6.3 定位型（EL3512/SE/SR）

    • 位置反馈：2V = 回缩，10V = 伸张。

    • 4–20mA 信号：需在端子 2–3 间并联 500Ω 电阻。

    • SE/SR：端子 3 与 7 短接，断电分别执行全伸 / 全缩。

    3.7 手动开关

    EL3512/SE/SR 可外接三位手动开关，实现强制伸 / 缩。

    3.8 弹簧预制接线要点

    • EL3501SE：230Vac 火线→端子 2。

    • EL3502SE：24Vac 中线→端子 2。

    • EL3512SE/SR：端子 3（中线）←→7（弹簧）短接。

    • 断电 → 弹簧自动动作到安全位置。

    4 调试

    4.1 弹簧预制（SE/SR 必做）

    1. 断电 → 拆端盖。

    2. 取下锁定片。

    3. 上拉弹簧手柄并释放，弹簧自动预紧。

    4. 保留锁定片备用。

    4.2 跳线设置（老款 EL3512/SE/SR）

    • W1：信号失效位置（回缩 / 中间 / 伸张，默认伸张）。

    • W2：输入信号 0–10V / 2–10V（用 4–20mA 必须设 2–10V）。

    • W3：10V 时伸张 / 回缩（默认伸张）。

    4.3 按钮设置（新款 EL3512/SE/SR）

    • W1（电位计）：失效位置 0~100% 连续可调。

    • W2（灯）：常亮 = 0–10V；不亮 = 2–10V。

    • W3（灯）：常亮 = 10V 伸张；灭 = 10V 回缩。

    5 维修

    通用原则

    • 任何维修必须先断电。

    5.1 执行器拆卸

    无弹簧型

    按 3.3 安装步骤反向操作即可。

    弹簧预制型（SE/SR）

    1. 断电 → 拆端盖 → 拆线。

    2. 转动弹簧手柄到行程中间。

    3. 按下手柄锁定，插入锁定片。

    4. 松开 U 型螺栓，取下执行器。
