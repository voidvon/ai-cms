    产品介绍

    1. 一段话总结

    EP6 防爆型电气定位器是斯派莎克生产的两线制回路供电设备，需 4~20mA 控制信号，适配直行程和角行程气动阀执行器，防爆等级涵盖 Ex db mb IIB T5 Gb 等多项认证，防护等级 IP66，工作环境温度 - 20~+60℃，供给压力 0.14~0.7MPa（1.4~7bar）；安装需由资质人员按中间 / 侧面 / 角行程等对应方式操作，接线需符合防爆要求并串联≤62mA 熔断器，调试核心为零点、行程及 A/M 开关设置，日常维护需清洁、检查气源与过滤器，故障可按症状对应排查，违规使用或安装可能引发安全风险。

    一、产品基础信息

    3. 详细总结

    一、产品核心信息

    1. 基础属性

      • 类型：防爆型电气定位器，两线制回路供电

      • 控制信号：4~20mA DC（需外部串联≤62mA 熔断器）

      • 适配执行器：直行程（弹簧回位隔膜 / 活塞执行器，如球阀、闸阀）、角行程（90° 旋角，如齿条齿轮式球阀、蝶形阀）

    2. 关键参数与认证

      项目具体内容
      工作环境温度-20~+60℃（-4~140°F），KCs 认证可达 - 20~70℃
      供给压力0.14~0.7MPa（1.4~7bar）
      防护等级IP66
      防爆等级Ex db mb IIB T5 Gb（多项认证统一等级）
      认证体系ATEX（证书 EPS21ATEX1035X）、IECEx（EPS21.0015X）、CCC（2021322307003890）、NEPSI（GYJ21.1186X）等
      耗气量约 2.5 LPM（1.4 bar g 供给压力下）

    二、安全操作规范

    1. 人员要求：需具有资质的人员执行 / 监督安装、调试、维护，需培训并遵守 “工作许可” 制度

    2. 防爆安全

      • 环境限制：适配 1 区 / 2 区（气体），禁用于 0 区

      • 设备要求：使用防爆电缆、密封接头、绝缘插头，闲置端口需封堵

      • 操作禁忌：打开封盖前必须完全断电并确认无残余电压；危险环境清洁需用湿布（防静电）

    3. 系统安全

      • 压力处理：安装 / 维护前需隔断压力并安全排放，采用双隔离措施，压力表为零不代表无压

      • 温度处理：隔离后需冷却至常温，防冰冻（无自排放功能产品需防护）

      • 防护装备：需根据场景配备防护服、护目镜等，避免化学 / 高低温 / 坠落物伤害

    三、安装流程

    1. 安装准备

      • 工具：内六角螺栓专用扳手、十字 / 一字螺丝刀、六角头螺栓扳手

      • 部件：定位器、安装套件（EY/UY/UBC 等系列）、供气管 / 信号管、导管密封接头

      • 前提：关闭阀门 / 执行器供给压力，使用旁路阀避免系统停机，确保执行器无残余压力；通风盖需朝下（防冷凝水损坏）

    2. 安装类型与步骤

      安装类型适配场景关键步骤配套套件
      直行程 - 中间安装直行程阀门，阀门升程 20/30/50/70mm1. 组装反馈杆与安装支架；2. 固定反馈销定位片；3. 定位器装配至执行器（反馈销啮合，反馈杆水平）；4. 固定安装支架EY1（20/30mm）、EY2（50/70mm）
      直行程 - 侧面安装直行程阀门，左侧安装1. 组装反馈杆与支架；2. 固定反馈销定位片（按标记对应升程）；3. 定位器装配并固定UY3（20/30mm）、UY1（50/70mm）
      角行程安装90° 旋角阀门，执行器杆高 20/30/50mm1. 按 VDI/VDE 3845 标准组装支架；2. 设定执行器角行程位置（双作用执行器重点）；3. 固定定位器并连接气路 / 电路角行程支架套件（2 个）

    3. 连接规范

      • 气路：SUPPLY（输入）、OUT（输出）接口为 ¼" NPT 母螺纹，气管外径≥6mm，检查无泄漏

      • 电路：导线规格 0.5-2.5mm²，屏蔽线（防干扰），接地柱至地阻抗＜1Ω，符合 ATEX/NEPSI 相关标准

    四、调试指南

    1. 基础设置：定位器需接地，线缆远离大功率变压器 / 电机（防干扰）；螺纹导管需用 PTFE 胶带密封（达 IP66 等级）

    2. 作用模式设置

      • 直行程：侧面安装（正作用装上部 M6 螺孔，反作用装下部）；中间安装（正作用装下部，反作用装上部）

      • 角行程：输入信号增强时顺时针旋转→凸轮 “DA” 面朝上；逆时针旋转→“RA” 面朝上，凸轮 “0” 标记对准行程调节器件轴承中心

    3. 核心调节

      • 零点调节：输入 4mA（或 20mA）初始电流，旋转零点调节器校准执行器初始位置

      • 行程调节：输入 20mA（或 4mA）终止电流，调整行程调节器（过少增大、过多减小），需与零点重复校准至无误后锁紧螺丝

      • A/M 开关：逆时针旋至 “M”（手动，供给压力直供执行器）；顺时针旋至 “A”（自动，按输入信号运行），手动后需复位自动

    五、维护与故障处理

    1. 日常维护

      • 清洁：用微湿的布或抗静电产品擦拭定位器

      • 气源：保持干燥、无油、无尘，检查供给压力稳定

      • 过滤器：定期排除油、水、杂质等杂物

    2. 故障排查（核心症状与解决）

      症状关键解决方法
      对输入信号无响应1. 检查供给压力≥1.4bar；2. 确认输入信号 4-20mA 正常；3. 校准零点 / 行程；4. 检查喷嘴是否阻塞（阻塞需返厂）
      OUT1 压力无法下降1. 检查 A/M 开关是否损坏；2. 检查喷嘴与挡板间隙及部件损坏（损坏需联系厂家）
      出现振荡1. 检查稳定弹簧是否错位；2. 排查阀门与执行器摩擦（增大执行器尺寸或减摩）
      线性度过低1. 确认直行程反馈杆 50% 点水平；2. 重新校准零点与行程；3. 更换不稳定的过滤减压阀

    六、退货与处置

    1. 退货要求：需提供姓名 / 公司信息、订单号、设备名称、故障描述；质保期内需附加购买日期、原始订单号、序列号；需用原始包装妥善包装并发送至当地斯派莎克分公司

    2. 处置原则：产品可回收，退货需书面提供污染物残留、健康安全环境风险及预防措施，附危险物质安全数据表

    4. 关键问题及答案

    问题 1：EP6 定位器的核心适配参数与防爆安全要求是什么？（侧重产品基础与安全红线）

    答案：核心适配参数：控制信号为 4~20mA DC，供给压力 0.14~0.7MPa（1.4~7bar），工作环境温度 - 20~+60℃，防护等级 IP66，适配 1 区 / 2 区（气体）直行程和角行程气动阀执行器；防爆安全要求：需使用防爆电缆、密封接头及绝缘插头，闲置端口封堵；打开封盖前必须完全断电并确认无残余电压；危险环境清洁用湿布（防静电）；电路需串联额定电流≤62mA 的熔断器；严禁用于 0 区爆炸性环境。

    问题 2：直行程定位器中间安装与侧面安装的核心区别的是什么？（侧重安装实操差异）

    答案：核心区别集中在适配场景、配套套件和安装细节：① 适配升程与套件：中间安装适配 20/30/50/70mm 升程，用 EY1（20/30mm）、EY2（50/70mm）套件；侧面安装为左侧安装，适配 20/30/50/70mm 升程，用 UY3（20/30mm）、UY1（50/70mm）套件；② 行程调节器安装：中间安装时，输入信号增强执行器轴向下移动为反作用（装下部 M6 螺孔）、向上移动为正作用（装上部）；侧面安装时，输入信号增强执行器轴向下移动为正作用（装上部）、向上移动为反作用（装下部）；③ 反馈销定位：中间安装需确保反馈销位于执行器中心线左侧，侧面安装需按定位片标记对应升程固定。

    问题 3：EP6 定位器调试的核心步骤及常见故障 “对输入信号无响应” 的排查流程是什么？（侧重调试与故障处理）

    答案：核心调试步骤：① 基础设置：定位器接地，线缆远离强干扰设备，螺纹导管用 PTFE 胶带密封；② 作用模式设定：直行程按安装方式确定行程调节器螺孔位置，角行程按执行器旋转方向固定凸轮（DA/RA 面朝上）；③ 零点与行程校准：输入 4mA（初始电流）调零点，输入 20mA（终止电流）调行程，重复校准至无误后锁紧螺丝；④ A/M 开关复位：手动模式使用后需旋回自动模式。“对输入信号无响应” 排查流程：① 检查供给压力是否≥1.4bar（弹簧回位型执行器需大于弹簧规格）；② 确认输入信号是否为 4-20mA DC 正常供给；③ 检查零点和行程调节器设置是否准确；④ 排查反馈杆安装是否正确啮合；⑤ 检查定位器喷嘴是否阻塞（若阻塞需返厂维修）。
